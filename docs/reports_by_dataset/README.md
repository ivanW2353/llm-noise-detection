# 按数据集分述的独立报告

每份报告覆盖一组实验的全过程：研究目标与动机、实验设置、实验过程、数据与分析、
理论解释、结论、局限，以及数据出处。

主报告 [`../report_zh/`](../report_zh/README.md) 按**研究问题**组织，同一问题下横向
比较所有数据集；本目录按**实验**组织，一组一份。两者取自同一批数据
（`results/{tag}/` 与 `results/eval/`）。

| 报告 | 数据集 | 一句话定位 |
|---|---|---|
| [dolly.md](dolly.md) | databricks-dolly-15k | 7 类程序化注入噪音，两个比例（10%/5%）；全部方法论工作在这里完成 |
| [oasst-wild.md](oasst-wild.md) | OASST2 | 天然噪音：人工 quality 标签而非注入，得到一个重要的负结果 |
| [triviaqa-ratio10.md](triviaqa-ratio10.md) | TriviaQA | 单一同质 QA 任务：噪音"内容"让危害差约 100 倍 |

每份报告只讨论自己的数据集，不与其他数据集横向比较——跨数据集的对照放在主报告里。

英文版：[`../reports_by_dataset_en/`](../reports_by_dataset_en/README.md)

## 三个数据集的共同设计

三个数据集覆盖三种不同的噪音来源与任务形态：

| 数据集 | 任务域 | 噪音来源 | 噪音比例 | 训练样本数 |
|---|---|---|---|---|
| `dolly` | 指令跟随（多样） | 程序化注入，7 类 | 10% 与 5% 两档 | 14611 |
| `oasst-wild` | 对话（多样） | 天然（人工 quality 标签） | 8.83% | 68762 |
| `triviaqa-ratio10` | 事实问答（单一同质） | 程序化注入，3 类 QA 专用 | ~10% | 137984 |

共同的训练与采集配置（三者完全一致）：Qwen2.5-3B-Instruct + LoRA（r=32, alpha=64,
dropout=0.05），5 epochs，`micro_batch=1` + `grad_accum=16`（等效 batch 16），
lr=2e-4，`max_len=1024`，seed=42。`micro_batch=1` 是方法前提而非性能选择——逐样本
梯度归属要求单个样本独立构成一次前向-反向。

**共同的硬约束**：检测全程不使用噪音标签。噪音标签只用于事后计算 AUC 等评价指标，
不参与打分器的构建。

**一处硬件差异**：`dolly` 与 `oasst-wild` 在 NVIDIA RTX PRO 6000 上完成，
`triviaqa-ratio10` 在 RTX 4090 上完成。这不影响特征数值（全部由落盘轨迹后处理算出，
由模型/数据/种子决定，两卡都原生支持 bf16），但**耗时类数字不能跨数据集比较**。

**共同的方法学限制**：每个数据集只有一个随机种子，没有方差估计，所以所有数字都只应读
方向与量级，不应读小数点后第三位。
