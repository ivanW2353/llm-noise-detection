# 跨实验综合: 噪音检测三连实验的结论汇总

> 综合三个实验: **qa-noise-experiment** (2026-07, SQuAD v1 抽取式 QA, 87K 样本, 1.5B) ·
> **dynanoise** (2026-08, dolly-15k 生成式, 1.5B/3B, loss 动力学信号) ·
> **llm-noise-detection** (本仓库, dolly-15k, 3B, 逐样本梯度 + 40 特征)

---

## 1. 三个实验的对应关系

| 噪音类型 | qa-noise | dynanoise | 本实验 | 检测难度 (本实验) | 清洗精度 P@10% | 危害性 |
|---|---|---|---|---|---|---|
| 表面损坏 | random_word | A (BPE 乱码) | garbled | **0.996** | **0.937** | **最轻** |
| 一致模式/快捷键 | fixed_wrong | E (shortcut "42") | template | **0.9995 (最易)**, 方向全反转 | 0.819 | **灾难级** (GSM8K -23%) |
| 重复冗余 | — | C (redundant) | duplicate | 0.982 (仅数据侧) | 0.721 | 过拟合损伤 |
| 语义错配 | random_replacement | B (LLM 流畅错答) | unrelated | 0.931 | 0.631 | 中等 (生成式) |
| 信息缺失 (截断) | — | — | truncation | 0.888 | 0.340 | 轻微 |
| 轻微改写 | — | — | near_duplicate | **0.733**, text_nn_sim 失效 (0.492) | 0.266 | 无可测危害 |

> 检测难度列为多变量 AUC (LR 或 RF 取优, 5 折 CV); P@10% = 丢弃打分最高 10% 时的精度 (随机基线 0.10)。
> truncation / near_duplicate 的"待验证"已于 2026-09-02 补齐: **near_duplicate 的 TF-IDF 漏检预测被证实** (0.492), 需语义嵌入; keyword 的"不可检 0.531"修正为"最难检 0.70-0.73" (原值受诊断子样本 + 单次划分两个伪影压低, 见主报告 §3.7)。

## 2. 跨实验一致的 8 条结论

### 2.1 "噪音 = 高 loss" 的方向直觉是错的, 且是普遍陷阱

- dynanoise: unlearnable 噪音的 $\text{loss\\_cv}$ 反而**低于** clean (0.013 vs 0.041); 修正方向 ($-\text{loss\\_cv}$) 后 A 类命中率从 3.8% 跃升至 86.5%;
- 本实验: duplicate 的 loss 也**低于**正常样本 (AUC 0.37, 方向反转);
- 本实验 template (2026-09-02 补测): **全部损失/熵特征方向反转且更极端** — loss_mean AUC **0.101**、hard_loss_mean 0.096、loss_curvature 0.102 (翻转后均 ≈0.90); 固定模板被完全记住, 损失远低于正常样本。这是三个实验中方向反转最强的案例;
- **结论**: 可被记忆/学习的噪音 (duplicate / 冗余 / 固定模板) 在 loss 侧呈反向信号, 且**越"可学"反转越极端**。任何检测器必须经验性验证方向, 采用双向 (zscore) 联合方案。

### 2.2 Token 级信号是跨实验最稳健的信号族

- dynanoise: $\text{token\\_loss\\_top20}$ 跨 1.5B/3B 完全稳定 (AUROC 0.947 ± 0.001), 也是唯一跨模型尺度稳定的信号;
- 本实验: `entropy` / `frac_hard` / `max_token_loss` / `user_loss` 是 garbled 检测的主力 (0.95~0.98);
- 本实验 token 级逐 token 梯度归因 (hard_loss AUC 0.77) 也确认 token 级信息有效;
- **结论**: 检测信号应优先考虑 token 级特征; 样本级聚合 (跨 token/epoch) 是可靠尺度。

### 2.3 噪音危害性由"任务类型"决定 — 跨实验最强的对比

| 任务 | 噪音 | 比例 | 影响 |
|---|---|---|---|
| SQuAD 抽取式 (qa-noise) | random_replacement (答案互换) | **50%** | EM 仅 -0.6% (几乎无害) |
| SQuAD 抽取式 | fixed_wrong (统一错答) | 50% | EM **-41.8%** (灾难) |
| dolly 生成式 (本实验) | unrelated (回复互换) | 10% | GSM8K -0.043 (最有害) |

- 抽取式任务中 context 自带答案 → 模型靠上下文兜底, label 噪音几乎无效;
- 生成式任务中 response 即知识 → 语义错配直接污染知识;
- **结论**: 噪音影响分析不能脱离任务类型; 同一噪音在抽取式任务无害、在生成式任务有害。

### 2.4 一致模式噪音 (template, dynanoise 称 shortcut) 是最危险且最需检测的类型

- qa-noise: fixed_wrong 近线性灾难 (-8.4 分/10%, R²≈0.99);
- dynanoise Phase 5: shortcut "42" 噪音 $\text{loss\\_cv}$ 检测弱 (0.67), 但 **IFD 有效 (0.90)** — 需要指令感知的信号;
- 本实验**恰好缺少这一类噪音** (4 类中无一致模式类) — 这是当前实验设计的已知缺口;
- **结论**: 一致模式噪音 = "高危害 + 可检测 (用对信号)" 象限, 是数据清洗的最高价值目标。

### 2.5 检测力与清洗收益解耦 — 过滤提升存在天花板

- dynanoise Phase 4: 三组独立实验中, 精准过滤 (RHO 命中 99.8%) 的 MT-Bench 提升 (+0.48) 仅略优于**随机丢弃 10%** (+0.41);
- 本实验: 10% 噪音对验证集几乎无影响 (6 模型 MMLU 极差 0.011, 且全部劣于基座);
- 本实验 (2026-09-02 补测) 给出了天花板的**第二个来源 — 精度不足**: 按 10% 预算清洗时, unrelated 的 precision 仅 0.631、keyword 0.281 — 即使检测 AUC 看起来很高 (0.93), 丢掉的样本里仍有 37% 是干净数据。**只有 garbled 达到零误伤** (P@5% = 1.000)。所以"清洗收益低"既因为噪音本身危害小, 也因为清洗操作本身会连带丢弃干净样本;
- **结论**: 低比例语义噪音的"过滤收益"极低 — 检测信号的价值应定位在**质量监控/审计/数据治理**, 而非"清洗后模型变强"; 若追求清洗收益, 应针对高危害类型 (shortcut/高比例 label 噪音)。

### 2.6 受控实验的信号方向在自然数据上成立

- dynanoise Phase 6 (lmsys-chat-1m, 50K): $\text{token\\_loss\\_top20}$ 与 $\text{loss\\_mu}$ 的 Spearman $\rho = -0.78$, 方向与受控实验一致 (AUROC 0.946);
- **结论**: loss 动力学信号可迁移到无标签的真实数据, 用于数据质量监控。

### 2.7 但"可迁移到无标签数据"不等于"无标签也能检测" (2026-09-02 新增)

三个实验此前报告的全部 AUC 都来自**有监督**检测器。本实验补测了四个无标签打分器 (IsolationForest / 双向 z-score / 马氏距离), 结果限定了 §2.6 的结论范围:
| 噪音类型 | 有监督 | 无标签最佳 | 无标签 P@10% |
|---|---|---|---|
| garbled (表面损坏) | 0.996 | **0.955** (iforest) | 0.640 |
| unrelated (语义错配) | 0.933 | 0.722 (iforest) | 0.243 |
| duplicate (可记忆) | 0.982 | 0.699 (iforest) | 0.083 |
| **template (一致模式)** | **0.988** | 0.633 (离群) → **0.9994 (带符号+集中度)** | **0.059 → 0.836** |

- **通用离群检测下只有表面损坏存活**; 而三个实验一致认定"最高价值目标"的一致模式噪音 (template / fixed_wrong / shortcut) 恰恰是**通用离群模型下最不可检**的;
- 机制上必然如此, 且与 §2.1 是同一件事的两面: 可被记忆的噪音在 loss 侧方向反转, 意味着它不是"离群"而是**"过度典型"** (loss/熵更低、损失更集中), 位于分布中心 — 任何单总体离群模型都找不到它;
- **但这个机制解释本身就是解法, 且已验证**: 改问"是否过于容易"而非"是否离群" —— 用**带符号**的记忆性规则 (低 loss + 快收敛 + 低梯度, 方向由假设先验固定) 使 template 从 0.633 回到 **0.887**, 再加上尺度无关的 top-20% 集中度特征达 **0.9994 (P@10% 0.836)**, 接近 0.988 的有监督上限。**无标签光谱是两端高、中间低的 U 形**: 一致模式 (过度典型) 与表面损坏 (离群) 两端可检, 而语义类噪音 (unrelated / keyword / near_duplicate) 在两种规则下均 ≤0.77 —— 这才是剩余的真实缺口;
- 代价是**必须事先知道找哪一端**才能选对符号; 若预期多类同时污染, 则应把预算按双尾花掉 —— 在混合 run 上双尾胜过单侧 (0.293 vs 0.083), 恰因多类污染同时占据两端 (§4.4)。这比"每类都要标注种子"弱得多 (一个先验假设 vs 一批标注), 但不是零知识;
- dynanoise Phase 6 证明的是**信号的相关性方向**在自然数据上保持, 不是"无需标签即可分离噪音"。两者常被混为一谈;
- **结论**: 无标签场景下应放弃通用离群检测, 改用带符号的规则 —— 猎捕记忆性噪音用**正向**联合规则 (低 loss + 低熵 + 高集中度), 猎捕表面损坏用离群模型; 若要免掉"先知道找哪一端"这个前提, 需用干净种子集标定每个特征的符号 (半监督, 尚未验证)。

### 2.8 检测器的迁移性: 换比例免费, 换类型失效 (2026-09-02 新增)

- **跨比例**: 10%↔5% 双向迁移保持率 0.995-1.156 (5 个数据集) — 污染率漂移不是问题, 检测器可直接跨比例部署; keyword 反而因训练噪音集翻倍而提升 0.11;
- **跨类型**: 非对角均值 0.688 vs 对角 0.899; duplicate↔garbled **互为反向预测** (0.46/0.48), template 是最差的迁移目标 (0.17-0.44);
- **结论**: 每个噪音 family 必须有自己的标注种子。这与 dynanoise 的"不同噪音类型需要不同信号" (loss_cv 对 shortcut 无效而 IFD 有效) 是同一现象在检测器层面的体现。

## 3. 检测难度光谱 (三实验合并)

```
可检测 ◄──────────────────────────────────────────────────────────► 难检测
一致模式(template/fixed_wrong)  表面损坏(garbled)  语义错配(unrelated)  轻改写(near_dup)  精致篡改(keyword)
AUC 0.9995  P@10% 0.82          0.996  0.937       0.931  0.631        0.733  0.266      0.70-0.73  0.281
数据侧/IFD/反向 loss 可检        训练侧可检          部分可检            数据侧特征失效     弱信号
(灾难性危害 GSM8K -23%)          (最轻危害)          (中等危害)          (无可测危害)      (低比例时无害)
```

**关键洞察**: 检测难度与危害性**不单调相关** — 最易检的 (template/garbled) 一个最危险一个最无害, 最难检的 (keyword) 低比例无害; 真正的"检测价值区"是**一致模式噪音** (可检且灾难) 与**高比例语义噪音** (难检但开始有害)。

> 用 precision@10% 而非仅 AUC 标注是必要的: unrelated 的 AUC 0.931 与 garbled 的 0.996 看起来接近, 但实际清洗精度是 0.631 vs 0.937 — AUC 系统性高估可用性 (本实验 2026-09-02 补测)。

## 4. 对当前实验的可借鉴改进 (按价值排序)

### 4.1 补一致模式噪音 template (原 shortcut, 最高价值) — ✅ 已完成 (extra10)
- 构造: 噪音样本统一回复固定错误模板;
- **结果超出预期**: 检测 RF **0.9995** (最易检类型), 危害最大 (GSM8K -23%) — "高危害+可检测"象限已补齐;
- **附带发现**: 其损失/熵特征**方向全面反转** (loss_mean AUC 0.101), 是三实验中反转最极端的案例 (见 §2.1); `hard_pos_jaccard` 0.808 (硬 token 位置恒定) 是该类型特有的指纹。

### 4.2 增加 token_loss_top20 集中度信号 — ✅ 已完成 (2026-09-02, `analyze_token_concentration.py`)
- 从已存的 top-32 token 明细离线计算真正的 top-20% 损失占比 (零 GPU 成本, 无需重训);
- **结果: 它是 template 的最强单特征 (0.9994**, 原最强 hard_loss_mean 0.904**), 且是 template 唯一未方向反转的特征** — 被记忆的模板损失集中在极少数分歧位置, 而**集中度比值是尺度无关的**, 因此在所有绝对损失水平塌陷后仍有效;
- **但不是通用信号**: garbled / keyword / near_duplicate 上仍不如现有的 entropy / frac_hard / max_token_loss。dynanoise 的"跨模型最稳信号"在本实验**复现但是类型专属的** — 它本质上是一个一致模式噪音检测器;
- 覆盖率如实测量: 精确 top-20% 需要 ≤32 个已存 token, 对 86-89% 的样本成立 (中位长度 41-50 token); `top20_share_ok` (截断时置 NaN) 与 `top20_share` 在 template 上小数点后 4 位一致, 说明截断不是结论的来源。

### 4.3 增加 IFD 信号 (Instruction-Following Difficulty) — ✅ 已完成并已评估 (三个 tag 齐备)
- 公式: $\text{IFD} = \dfrac{L(A \mid Q)}{L(A)}$ (需一次额外前向, 对 prompt-only 输入);
- **对 dynanoise 结论的修正**: IFD 的**均值**跨类型差异极大 (template 0.005 vs garbled 0.534, 100 倍以上), 但**单变量 AUC 只有 0.55-0.80**, 全部低于同类型的 loss/熵特征 — "IFD 是跨类型区分度最强的单一指标"这一表述在补测后不成立 (均值差异 ≠ 可分);
- **真正的价值是增量**: IFD 比值本身几乎无增量 (+0.000~+0.012), 但把分子分母 `L(A|Q)` / `L(A)` 作为**两个独立特征**加入 13 维轨迹特征后, template +0.028 (0.967→0.995)、unrelated +0.024、7-way mixed +0.022 — 比值把两个有用的自由度压成了一个;
- **建议**: 作为可选特征列用于 template/unrelated 类型, 不进默认 `METRIC_ORDER` (收益集中在少数类型, 成本是全局的)。

### 4.4 双向信号显式化 — ✅ 已测试, **结论是否定的**
- 本实验 RF 已隐式学到 duplicate/template 的"低 loss"方向, 报告 §7.2 与 §2.1 已显式记录反转;
- 阈值化方案已实测 (§3.9): 双向 |z| 打分器 (`zscore_max`) 是四个无标签打分器中**最差的** (template 0.418, duplicate 0.598) — 取绝对值确实换来方向无关性, 但代价是**丢掉了真正携带信号的方向信息**;
- 双尾预算方案 (两端各取 5%) 的实测结果按场景分裂: 对**单一**类型无效 (template 仅 0.092, 低于随机 0.10 —— 一端是纯干净样本, 一半预算被浪费), 但对**多类混合污染反而胜出** (mixed 0.293 vs 单侧 0.083, 随机的 2.4 倍), 因为混合 run 的噪音同时分布在两端;
- **修正建议已验证**: 阈值型检测器必须用**带符号**的方向, 且符号需按噪音类型标定。实测结果 (本仓库 §3.13): 带符号的记忆性规则使 template 从 0.633 → **0.887**, 加上尺度无关集中度达 **0.9994 (P@10% 0.836)**; 但同一符号在 garbled 上是 **0.015 (完全反向)** —— 符号本身就是"要找哪一类噪音"这一先验知识的载体。实用配方: **猎捕单一已知类型用带符号单侧, 预期多类污染用双尾**。

### 4.5 清洗收益对照实验 (验证 dynanoise 的"天花板"结论) — **仍未做, 当前最大缺口**
- 跑 2 个 run: 按检测分数移除 top-10% vs 随机移除 10% → 对比验证集;
- 预期: 提升极小, 复现 dynanoise 的 random_drop ≈ 精准过滤;
- 本实验已补齐"检出率"与"清洗精度"两环 (§3.7), 但"清洗后模型是否更好"这一环仍只能引用 dynanoise 的结论;
- 成本: 2 个 run + 2 次评测 (~10h)。

### 4.6 自然数据信号验证 (复现 Phase 6) — ✅ 已完成 (2026-09-02 晚)
- **dynanoise Phase 6**: lmsys-chat-1m (50K), Spearman(token_loss_top20, loss_mu) = **−0.78**
- **本项目 §3.14**: lmsys-chat-1m (n=15,404), 用 ratio10 clean 模型, Spearman = **−0.839** (更强), p < 1e-300
- **两个独立实验**在不同模型/数据上均观测到: token 级集中度与样本难度负相关
- **但这只证实"信号相关性方向迁移", 不证实"可以无标签检测噪音"** — dynanoise Phase 6 与本项目 §3.14 都是**纯相关性测量**, 自然数据无真值、无法算 AUC; §3.9/§3.13 的无标签检测是独立问题, 且结论是 U 形光谱 (两端可检、中段不可检)
- 附带发现: token_top20 与 loss_cv **近乎完全共线** (ρ=+0.982) — 两者测同一件事, 特征集里只留一个

### 4.7 RHO 参照对比
- dynanoise 用 holdout 模型作 RHO 基准; 本实验用 cos_sim_ref (LESS 式) 作参考方向;
- 可在分析中加一列 RHO 式信号 (需训练 1 个 holdout 模型, ~3.5h) 作为对照基准。

## 5. 一句话总结

> 三个实验共同说明: **loss 动力学信号真实有效但方向常反转 (越可学越反转)、token 级最稳、危害由任务类型决定、一致模式噪音最危险、清洗收益有天花板 (既因噪音危害小, 也因清洗精度不足)** — 检测技术的价值在于数据治理与质量监控, 而最高价值目标是一致模式/高比例语义噪音, 而非最容易检测的表面乱码。

> 2026-09-02 补充的三条: **AUC 系统性高估清洗可用性** (unrelated AUC 0.931 → P@10% 仅 0.631); **多类噪音混合不稀释单类型信号** (混合 run 内每子类型可检性 ≥ 其单类型 run) —— 说明真实的多类污染场景应"按类型分别打分再取并集", 而非训练统一的二分类器; 以及**无标签检测是 U 形而非单调** —— 通用离群模型只抓表面损坏, 但换成带符号的"过度典型"规则后一致模式噪音也可检 (template 0.9994 / P@10% 0.836), 剩余的真实缺口是**中间的语义类噪音**。
