# 噪声检测实验分析报告

**日期**：2026-09-16
**范围**：`ratio10`（10% 噪音，9 个数据集，训练 + 分析 + 下游评测全部完成）、`ratio5`（5% 噪音，交叉验证，同样全部完成）
**图表**：`results/charts/*.png`（由 `scripts/make_report_charts.py` 生成；脚本本身不纳入 git 跟踪，产出的 PNG 纳入跟踪）
**英文版**：[`../report_en/`](../report_en/README.md)

本项目研究一个核心问题：**在完全不使用噪音标签的前提下，能否仅凭 LoRA 微调过程中的训练动态（loss 轨迹、梯度范数、余弦相似度等）识别出被注入的低质量/异常训练样本？**

三个最主要的结论：

- **检测能力强烈依赖噪音机制。** 乱码/模板化/完全重复的有监督 AUC > 0.98，关键词替换/近似重复只有 0.577/0.674，而且后者的限制不是打分方式选错，是信号本身不在训练动态里（第 5.2 节预测、6.11 节验证）。
- **存在方向反转陷阱。** 模板化这类"被记忆"的噪音表现为 loss 异常低、收敛异常快，通用离群检测在它上面接近随机（0.522），必须换成带符号的规则才能到 0.925（第 6.6 节）。
- **排序质量不等于清洗收益。** garbled 上定向剔除精度是随机的 5.7 倍却零下游收益；模板化上方向正确的打分器回收了 GSM8K 缺口的 70%，而方向错误的打分器比不清洗更糟（第 6.13 节）。
